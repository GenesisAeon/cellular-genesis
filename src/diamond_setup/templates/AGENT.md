# AGENT.md — GenesisAeon Release & Metadata Rules

This file is generated by `diamond scaffold --template genesis` and governs automated agent behaviour for GenesisAeon science packages.

## Release Checklist

Before tagging a release:

1. **Version bump** — update `__version__` in `src/<package>/__init__.py` and `pyproject.toml`.
2. **CREP constants** — verify `GAMMA_*` value matches `arctanh(η) / σ` for the domain's threshold ratio.
3. **Benchmark** — run `python -m pytest tests/ -v` and confirm `run_benchmark()` returns `all_pass: True`.
4. **Zenodo record** — call `system.to_zenodo_record()` and confirm `package_number`, `gamma`, and DOIs are correct.
5. **`.zenodo.json`** — keep in sync with `to_zenodo_record()` output.
6. **Changelog** — add entry to `CHANGELOG.md` (create if absent).
7. **Tag** — `git tag vX.Y.Z && git push --tags`.

## Metadata Rules

| Field | Rule |
|-------|------|
| `package_number` | Integer matching the GenesisAeon Entropy Atlas entry (e.g. 25) |
| `gamma` | Must equal `arctanh(H*/K) / sigma_CREP` to 3 decimal places |
| `domain` | Lowercase hyphenated string (e.g. `cell-biology`) |
| `REFERENCE_DOI` | Primary literature DOI for the domain |
| `creators` | `[{"name": "Römer, Johann", "affiliation": "MOR Research Collective"}]` |
